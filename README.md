# Module 22 Assignment — React Hooks Practice

**Technology:** React.js · Vite · JavaScript · CSS

## Tasks

| # | Task | File |
|---|------|------|
| 1 | useState Counter (Increase / Decrease) | `src/components/Counter.jsx` |
| 2 | Show/Hide "Hello React" text | `src/components/ShowHideText.jsx` |
| 3 | Display input value on button click | `src/components/InputValue.jsx` |
| 4 | Focus input field using `useRef` | `src/components/FocusInput.jsx` |
| 5 | Update user object with spread operator | `src/components/UserObject.jsx` |
| 6 | Print "Component Loaded" in console using `useEffect` | `src/components/Welcome.jsx` |

## How to Run

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).
